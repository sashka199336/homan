CUSTOMER SERVICE отвечает за управление данными клиентов банка.

Технологический стек:

Язык программирования: Java 21.
База данных: PostgreSQL.
API: REST.
Брокер сообщений: Kafka.
Безопасность: Шифрование данных в PostgreSQL

Функции сервиса:

1. Заведения нового клиента Функция предназначен для использования сотрудниками банка для автоматизации процесса заведения 
новых клиентов в систему.
2. Получение клиентских данных	Функция предназначена для использования пользователями (сотрудниками, клиентами) и связанными 
сервисами для предоставления информации о клиентах.
3. Редактирование клиентских данных Функция позволяет сотруднику редактировать данные существующих клиентов.
